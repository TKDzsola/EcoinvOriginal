ÚJDONSÁGOK ÉS JAVÍTÁSOK:

1. PÉNZÜGYI PONTOSSÁG
   - Teljes Euro (€) alapú elszámolás bevezetése minden 
     felületen és a PDF bizonylatokon.
   - Szigorú kerekítési algoritmus a háttérben, amely 
     felszámolja a filléres eltéréseket a tartozásoknál.

2. KINTLÉVŐSÉG-KEZELÉS
   - Automatikus figyelmeztetés az ügyfél kiválasztásakor, 
     ha az adott partnernek rendezetlen számlája van.
   - Új kintlévőség-összesítő kártya az ügyfél adatlapon.
   - Dinamikus színjelzés: Piros sáv kintlévőség esetén, 
     Zöld sáv teljes rendezettség esetén.

3. SZÁMLAKERESŐ FUNKCIÓK
   - Számlastátusz szerinti szűrés lehetősége (Kész, Sztornó).
   - "Teljes befizetés" gyorsgomb: egy kattintással rögzíthető 
     a számla teljes kiegyenlítése.
   - Javított tizedesjegy-megjelenítés az oszlopokban.

4. PDF BIZONYLATOK
   - Professzionális, kétnyelvű (Német/Magyar) fejléc és lábjegyzet.
   - Következetes Euro (€) szimbólum használat a végösszegeknél.
